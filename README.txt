FOR SHARMI — MY FAV HUMAN ♡

1. Open this folder in VS Code.
2. Open index.html in your browser (or use the Live Server extension).
3. Put your own photos and videos inside the assets folder.
4. To show a photo, replace a placeholder <div class="photo-placeholder">...</div>
   with: <img src="assets/your-photo.jpg" alt="A memory of us">
5. To add a video, replace the video-placeholder block with:
   <video controls playsinline>
     <source src="assets/your-video.mp4" type="video/mp4">
   </video>
6. Before publishing, personalise the timeline, captions and letter with your own memories.

GITHUB PAGES:
- Create a new public repository (or a private one if your Pages plan/settings allow it).
- Upload index.html, style.css, script.js and the assets folder.
- In repository Settings > Pages, choose Deploy from a branch, select main / root, and save.

Tip: Compress large videos before uploading. Avoid putting private or sensitive photos online
unless your friend is comfortable with them being accessible through the website link.
